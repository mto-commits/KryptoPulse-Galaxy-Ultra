KryptoPulse GALAXY ONE v9.2.0 — SERVER DATA ENGINE

1. Luo ilmainen Cloudflare Worker nimellä kryptopulse-market.
2. Kopioi server/worker.js Worker-editoriin ja Deploy.
3. Saat osoitteen, esim. https://kryptopulse-market.<oma-subdomain>.workers.dev
4. Julkaise tämän ZIPin index.html + manifest + sw.js + ikonit kuten ennenkin.
5. Avaa Galaxy -> Näytä analyysimoottori -> API DIAGNOSTICS.
6. Syötä workers.dev-osoite kohtaan DATA SERVER ja paina Tallenna DATA SERVER.
7. Paina Testaa serveri. Tilan pitää muuttua LIVE.
8. Palaa ylös ja paina SKANNAA. Ylätilan pitäisi nousta CORE 1/2 tai CORE 2/2.

Vaihtoehto: avaa Galaxy kerran parametrilla ?proxy=https://kryptopulse-market.<oma-subdomain>.workers.dev
Galaxy tallentaa osoitteen selaimen localStorageen.

Turvallisuus: Worker ei sisällä pörssien kaupankäynti- tai withdrawal-avaimia. Se hakee vain julkista markkinadataa.
